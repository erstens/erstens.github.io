安装

macOS：解压后把 Pilot Agent 拖到「应用程序」。若系统提示无法打开，在 Finder 里按住 Control 点按该 App，选择「打开」。

Windows：双击运行。程序需要管理员权限。若出现 SmartScreen 提示，选择「更多信息」，再选择「仍要运行」。

Linux：下载后改名为 pta 并加执行权限，例如 chmod +x pta-linux-amd64 && mv pta-linux-amd64 pta && ./pta。需要代理时加 --proxy；注销用 pta --revoke。
